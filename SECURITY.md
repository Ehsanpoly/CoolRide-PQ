# Security policy

CoolRide-PQ is pre-production software and must not be connected directly to operational technology without a site-specific cybersecurity and safety review.

Please report suspected vulnerabilities privately to the repository maintainer. Do not include credentials, real facility addresses, network diagrams, or exploitable production details in a public issue.

Production hardening requirements include identity federation, least-privilege authorization, certificate lifecycle, signed configuration and releases, software bill of materials, dependency scanning, immutable audit storage, OT/IT segmentation, allow-listed command paths, rate limits, replay protection, clock integrity, backup/restore, and incident response exercises.
